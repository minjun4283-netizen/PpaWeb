# PPA 대시보드 사용 가이드 (처음 사용하시는 분용)

이 문서 하나로 "다운로드 → 설치 → 매일 사용 → 문제 해결"까지 전부 다룹니다.
이미 아는 내용은 건너뛰고 필요한 절만 찾아 보셔도 됩니다.

> 이 저장소에는 사실 세 가지 결과물이 들어 있습니다 — 헷갈리지 않도록 먼저
> 정리합니다.
>
> | 폴더 | 상태 | 이 가이드에서 다루나요 |
> |---|---|---|
> | `static-dashboard/` + `vba-form/` | **지금 실제로 쓰는 조합** | ✅ 이 문서 전체가 이 이야기입니다 |
> | `backend/` + `frontend/` | 사내망 서버가 생기면 쓸 별도의 편집 가능한 웹앱(아직 배포 안 함) | ❌ (자세한 내용은 `README.md`) |

---

## 0. 큰 그림 — 뭐가 어디서 도는지

```
                 ┌───────────────────────────┐
   입력/수정  →  │   PPA파일.xlsm (엑셀)      │
  (매크로 버튼)   │   입력폼 · 탐색 · 매크로들  │
                 └───────────┬───────────────┘
                              │ "대시보드 생성" 또는
                              │ "실시간 입력 서버 시작" 버튼
                              ▼
                 ┌───────────────────────────┐
   조회/공유  ←  │  PPA현황.html (단일 파일,   │
  (브라우저)      │  xlsm과 같은 최상위 폴더)   │
                 └───────────────────────────┘
```

(실행에 필요한 스크립트들은 `_program\static-dashboard\` 안에 따로
모여 있습니다 — 평소에 직접 열어볼 일은 거의 없습니다.)

- **실제 데이터는 항상 엑셀 파일 하나(`PPA파일.xlsm`)에만 저장됩니다.** 대시보드는
  그 내용을 보여주는 화면일 뿐입니다.
- 대시보드를 만드는 방법은 두 가지입니다 — 뒤에서 자세히 설명합니다.
  - **A. 대시보드 생성** (버튼 한 번 → 조회용 HTML 하나 새로 만들고 끝, 서버 없음)
  - **B. 실시간 입력 서버** (버튼 한 번 → 계속 떠 있는 서버, 브라우저에서 입력해도
    Windows COM으로 엑셀에 바로 반영됨)
- 인터넷도, 사내 서버도 필요 없습니다 — 전부 사용자 PC 안에서만 돕니다.

---

## 1. 다운로드

1. 저장소 페이지에서 **Code → Download ZIP**을 누릅니다.
   - ⚠️ 개별 파일을 Raw로 열어 "다른 이름으로 저장"하면 안 됩니다 — UTF-8로
     저장되어 `.bat`/`.bas` 파일의 한글이 깨집니다. 반드시 ZIP 전체 다운로드를
     쓰세요.
2. 압축을 풉니다.

---

## 2. 폴더 배치

압축을 푼 뒤, **실제 사용할 엑셀 파일과 `_program` 폴더가 같은 위치에
나란히** 있어야 합니다. 이 구조를 벗어나면 버튼이 파일을 못 찾습니다.

```
📁 (원하는 이름의 작업 폴더)\
   PPA파일.xlsm              ← 실제로 열어서 쓰는 엑셀 (매크로 넣을 파일)
   PPA현황.html              ← 실행하면 여기 자동으로 생김(매일 여는 파일)
   PPA현황_snapshot.json     ← 자동 생성/갱신 - 지우지 마세요
   📁 _program\              ← 압축 푼 것 중 이 폴더 전체를 그대로 복사
      📁 archive\             ← 저장/생성/종료 시 자동 백업(4-3절 참고)
      📁 python-embed\        ← PC에 python이 안 깔려 있을 때만 필요 (3절 참고)
      📁 static-dashboard\
         dashboard_recreate.bat
         run_live_server.bat
         stop_live_server.bat
         ppa_liveserver.py
         excel_com.py
         dashboard_form.js
         build_dashboard.py, ppa_schema.py, ppa_loader.py, ppa_changes.py,
         ppa_dashboard_render.py, make_demo.py
         vendor\                 ← 동봉된 openpyxl (건드리지 마세요)
         README.md
```

- `_program` **폴더 전체**를 옮겨야 합니다 — 안에 있는 파일만 따로
  빼서 옮기면 안 됩니다(서로 참조하는 파이썬 모듈들이라 다 같이 있어야 함).
- 실행하다 만들어지는 산출물(`PPA현황.html`, `PPA현황_snapshot.json`)은
  **작업 폴더 최상위**에 자동으로 생깁니다 — 지우지 마세요(지우면 [변경]
  탭 비교가 처음부터 다시 시작됩니다).

### Python이 이미 깔려 있는지 모르겠다면

명령 프롬프트(`Win+R` → `cmd`)에서 `python --version`을 쳐보세요. 버전이
나오면 이미 있는 것이니 3절은 건너뛰어도 됩니다.

### Python이 안 깔려 있다면 (사내망이라 설치가 어려운 경우)

1. 인터넷 되는 PC에서 <https://www.python.org/downloads/windows/> 접속
2. **"Windows embeddable package (64-bit)"** zip 다운로드 (설치 프로그램이
   아니라 압축만 풀면 되는 휴대용 버전)
3. 압축 푼 내용을 위 구조대로 **`_program\python-embed`**(즉
   `static-dashboard`와 같은 위치)에 둡니다.
4. `dashboard_recreate.bat`/`run_live_server.bat`이 PATH에 python이 없으면
   자동으로 이 폴더를 찾아 씁니다 — 따로 설정할 것 없습니다.

## 3. 엑셀에 매크로 넣기 (최초 1회)

> 먼저 **원본 xlsm의 사본**에서 연습해보시길 권장합니다.

1. 준비된 `PPA파일.xlsm`을 엽니다.
2. `Alt` + `F11` → VBA 편집기가 열리면 **파일 → 파일 가져오기**
3. 아래 세 개를 순서대로 가져옵니다(`vba-form` 폴더 안에 있습니다):
   | 파일 | 만들어지는 시트 | 용도 |
   |---|---|---|
   | `PPA_통합입력폼.bas` | `입력폼` | 6개 표 통합 입력/조회/수정 |
   | `PPA_탐색폼.bas` | `탐색` | 조인된 화면에서 바로 찾아 수정 |
   | `PPA_대시보드생성.bas` | `대시보드생성` | 대시보드 생성 버튼 두 개 |
4. 왼쪽 프로젝트 목록에 모듈 이름이 **한글 깨짐 없이** 들어왔는지 확인합니다.
   깨져 보이면(예: 물음표·네모) `vba-form/README.md`의 "이미 오류가 났다면"
   절차를 따라주세요 — ZIP 대신 개별 파일을 Raw로 저장했을 때 흔히 생깁니다.
5. VBA 편집기를 닫고, 엑셀에서 `Alt` + `F8` (매크로 실행 창)을 엽니다.
6. 아래 세 매크로를 **한 번씩** 실행합니다(이후로는 각 시트의 버튼만 쓰면
   됩니다):
   - `폼_만들기` (또는 `PPA_InputForm`이 만드는 시작 매크로 이름) → `입력폼`
     시트 생성
   - `탐색_만들기` → `탐색` 시트 생성
   - `대시보드_만들기` → `대시보드생성` 시트 + 버튼 두 개 생성

이제부터 파일을 열 때마다 세 시트와 버튼이 그대로 남아 있습니다(매번 다시
가져올 필요 없음 — xlsm 파일 자체에 저장됨).

## 4. 매일 쓰는 흐름

### 4-1. 데이터 입력/수정

`입력폼` 시트 또는 `탐색` 시트에서 합니다. 두 시트 다 저장 전에 필수값·참조
관계(PK/FK)를 확인하고 저장합니다. 자세한 사용법은
`vba-form/README.md`, `vba-form/README_탐색폼.md` 참고.

### 4-2. 팀원에게 보여줄 대시보드 만들기 — 두 가지 방법 중 선택

**방법 A. [대시보드 생성] 버튼 — 가장 간단, 서버 없음**

1. 입력폼/탐색에서 저장까지 마칩니다.
2. `대시보드생성` 시트의 **[대시보드 생성]** 버튼 클릭
3. 검은 콘솔 창이 잠깐 떴다 사라지고, `PPA현황.html`이 자동으로 열립니다.
4. 이 HTML **파일 하나**를 메일/Teams/공유폴더로 보내면 누구나 서버·설치
   없이 브라우저로 바로 봅니다. 단, **이 파일 자체는 조회 전용**입니다 —
   값을 못 고칩니다.
5. 다음에 또 바뀐 내용을 보여주려면 버튼을 다시 누르면 됩니다. [변경] 탭에는
   **마지막으로 리셋한 시점 대비** 추가/수정/삭제가 계속 누적되어 표시됩니다
   (버튼을 여러 번 눌러도 초기화되지 않음). 새로 기준을 잡고 싶으면 실시간
   입력 서버의 "간편 입력/저장" 창에 있는 [변경 비교 기준 리셋] 버튼을
   쓰거나, `python build_dashboard.py ... --reset-snapshot`으로 다시 만드세요.

**방법 B. [실시간 입력 서버 시작] 버튼 — 브라우저에서 직접 입력·삭제까지**

이건 팀원들이 **엑셀을 직접 열지 않고도 브라우저에서 입력/수정/삭제**할 수
있게 해주는 기능입니다. 저장·삭제를 누르면 Windows COM으로 실제 엑셀 파일에
그대로 반영됩니다.

1. **최초 1회만**: pywin32 설치 필요 (아래 5절)
2. `대시보드생성` 시트의 **[실시간 입력 서버 시작]** 버튼 클릭
3. **콘솔 창도 안내 창도 뜨지 않습니다** — 정상적으로 시작되면 몇 초 뒤
   브라우저만 자동으로 열립니다 (`http://127.0.0.1:8842`). 서버는 화면에
   안 보이는 채로 계속 실행됩니다(끄는 방법은 7번). 문제가 있을 때만(엑셀/
   python을 못 찾음, 서버가 응답하지 않음) 안내 창이 뜹니다.
4. 대시보드 화면 오른쪽 아래 **"간편 입력/저장"** 버튼을 눌러도 되고, **각
   표 탭의 "+ 추가" 버튼**이나 **행을 클릭했을 때 뜨는 상세 화면의
   "수정"/"삭제" 버튼**을 눌러도 같은 폼이 그 표/레코드가 선택된 채로
   열립니다 → 값 입력 → **엑셀에 저장**
   - 그 순간 엑셀이 열려 있으면 화면의 셀이 바로 바뀝니다.
   - **공급기한/계약일 등 날짜 항목**은 달력 아이콘을 눌러 고르거나
     `YYYY-MM-DD` 형식으로 직접 타이핑해도 됩니다.
   - 필수값이 비었으면 입력 중에 바로 빨간 테두리로 표시되고, 저장 시
     잘못된 참조(FK)가 있으면 엑셀에 쓰지 않고 먼저 알림(토스트)으로
     알려줍니다.
   - 저장 즉시 대시보드 화면도 자동으로 새로고침되고, **보고 있던 탭으로
     그대로 돌아옵니다**(홈으로 이동하지 않습니다).
   - 폼 위쪽 **👤 표시 이름** 칸에 이름을 한 번 입력해두면(비워두면 이
     컴퓨터의 Windows 로그인 계정이 자동으로 쓰입니다) [변경] 탭 이력에
     "누가" 바꿨는지 함께 기록됩니다.
   - **구매계약/판매계약/전기사용지/수급매칭**은 ID를 직접 입력하지 않습니다
     — 관련 필드를 채우면 자동으로 계산되어 미리보기로 뜨고, **저장 버튼을
     누르면 그 ID를 한 번 더 보여주는 확인 창이 뜹니다**. 자세한 규칙은
     4-4절 참고.
5. 기존 데이터를 지우려면: **컬럼별 검색 상자에 키워드를 입력해 그 데이터를
   먼저 불러온 뒤**(또는 상세 화면의 "삭제" 버튼으로 바로) → **삭제** 버튼
   클릭 → 다른 표에서 이 데이터를 참조하고 있으면 목록으로 보여주며 삭제를
   막고, 없으면 "정말 삭제할까요?" 확인 후 지워집니다. 삭제도 엑셀 파일에
   바로 반영되고 [변경] 탭에 "삭제된 항목"으로 표시됩니다.
6. 서로 연결된 표를 한 번에 입력·삭제하고 싶으면 폼 위쪽에서 **그룹A(발전소+
   구매계약)** 또는 **그룹B(수요기업+판매계약+전기사용지)**를 선택하세요.
   마스터를 불러오면 딸린 자식(과 손자) 데이터가 자동으로 함께 펼쳐지고,
   "+ 추가"/"삭제 표시"로 편집한 뒤 **일괄 저장**을 누르면 전부 한 번에
   검증하고(하나라도 문제가 있으면 아무것도 반영하지 않음) 통과해야 엑셀에
   반영됩니다.
7. 다 쓰면 **엑셀에서 파일을 닫거나, 대시보드 탭을 닫기만 하면 서버도
   자동으로 함께 꺼집니다** — 별도로 끌 필요가 없습니다. (콘솔 창이
   없어서 눈에 보이는 종료 방법이 없었는데, 이제 신경 쓸 필요가 없어졌습니다.)
   혹시 자동으로 안 꺼졌으면(브라우저를 통째로 강제 종료했을 때 등)
   `_program\static-dashboard\stop_live_server.bat`을 실행해 수동으로 끌 수
   있습니다. 콘솔을 직접 보면서 진행 상황을 확인하고 싶으면
   `_program\static-dashboard\run_live_server.bat`을 대신 더블클릭하세요(예전처럼
   검은 콘솔 창이 뜨고, 그 창을 닫아도 자동으로 종료됩니다).

> **둘 중 뭘 써야 하나요?** 그냥 최신 상태를 보고서처럼 공유만 하고 싶으면
> **방법 A**, 팀원이 엑셀 없이 브라우저에서 직접 입력까지 하길 원하면
> **방법 B**를 쓰세요. 둘 다 같은 `PPA현황.html`/스냅샷을 공유하므로 아무
> 때나 섞어 써도 [변경] 탭 누적은 끊기지 않습니다.

### 4-3. 자동 백업(archive)

방법 A로 [대시보드 생성]이 성공할 때마다, 그리고 방법 B의 서버를 통해
저장/삭제하거나 서버를 끌 때마다, 그 시점의 엑셀 파일과 방금 만든 HTML을
`_program\archive\`에 시각을 붙인 이름(`PPA파일_20260115_093000.xlsm` 등)
으로 자동 복사해둡니다. 실수로 잘못 저장했거나 파일이 깨졌을 때 이 폴더에서
이전 버전을 꺼내 쓸 수 있는 안전장치입니다. 확장자별로 최근 100개만 남기고
오래된 것부터 자동으로 정리되므로 디스크가 계속 차오르지는 않습니다 —
따로 관리하실 필요는 없습니다.

### 4-4. 자동 채번(ID) — 구매계약/판매계약/전기사용지/수급매칭

방법 B(실시간 입력 서버)에서 이 4개 표를 입력·수정할 때만 적용되는
기능입니다(입력폼/탐색 시트에서는 여전히 직접 입력).

- **구매계약ID** = `구매-발전소ID-공급기한_구매의 연도-순번`
- **판매계약ID** = `판매-수요기업ID-공급기한_판매의 연도-순번`
- **전기사용지ID** = `전기사용지-수요기업ID-연도-순번-전기사용지명` (수요기업·연도는
  선택한 판매계약에서 그대로 가져옴)
- **수급매칭ID** = `매칭-수요기업ID-연도-순번` (수요기업·연도는 선택한
  전기사용지 → 그 판매계약에서 가져옴)

관련 필드를 채우는 대로 화면에 계산된 ID가 바로 미리보기로 뜨고, **"엑셀에
저장"을 눌러야 최종 확인 창이 한 번 더 뜹니다** — 거기서 "이 ID로 저장"을
눌러야 실제로 반영됩니다("취소"하면 아무 일도 안 일어남).

**계약을 아직 안 맺은 임시 건**은 공급기한 입력칸 옆의 "임시 계약(공급기한
미정)" 체크박스를 누르세요 — 날짜 칸이 비워지고 ID의 연도 자리가 `T`로
표시됩니다(예: `구매-P001-T-01`). 나중에 실제 날짜가 정해지면 체크를 풀고
날짜를 입력해 저장하면, ID가 자동으로 실제 연도로 바뀝니다.

**이미 저장된 데이터의 근거 필드(발전소ID/수요기업ID/공급기한 등)를 나중에
고치면 ID가 자동으로 다시 계산되고, 그 ID를 참조하던 다른 표(수급매칭·
전기사용지)도 함께 자동으로 갱신됩니다.** 저장 전 확인 창에 몇 건이 함께
바뀌는지 그대로 표시되니 확인 후 저장하면 됩니다.

## 5. pywin32 설치 (방법 B를 쓸 때만 필요)

명령 프롬프트에서:

```
python -m pip install pywin32
```

- **python-embed를 쓰고 있다면** pip이 기본적으로 없으므로, 먼저
  <https://bootstrap.pypa.io/get-pip.py>를 받아 `python.exe get-pip.py`로
  pip을 넣은 뒤 위 명령을 실행하세요. (`python-manager` 설치 프로그램으로
  Python을 깔았다면 pip이 이미 들어있으므로 이 단계는 필요 없습니다.)
- 설치 후 레지스트리 등록(`pywin32_postinstall.py`) 같은 추가 작업은
  **필요 없습니다.**
- pywin32가 없으면 [실시간 입력 서버 시작] 버튼을 눌러도 콘솔 창에 바로
  안내가 뜨고 멈춥니다(조용히 실패하지 않습니다).

### 인터넷이 전혀 안 되는 VDI라면 (오프라인 설치 절차)

핵심은 **"인터넷 되는 PC에서 미리 받아두기"**와 **"VDI에서 그걸로 설치하기"**를
분리하는 것입니다. `pip download`는 반드시 인터넷 되는 PC에서만 실행하세요 —
인터넷이 안 되는 VDI에서 실행하면 그 자체가 실패합니다.

**① 인터넷 되는 PC에서 (한 번만)**

1. Python 설치 프로그램(예: `python-manager-26.3.msix`)으로 VDI와 **같은
   버전**의 Python(예: 3.14)을 설치합니다.
2. 명령 프롬프트에서:
   ```
   mkdir C:\pywin32_files
   pip download pywin32 --no-deps -d C:\pywin32_files
   ```
   → `C:\pywin32_files` 폴더 안에 `pywin32-...-cp314-cp314-win_amd64.whl`
   같은 이름의 파일이 자동으로 생깁니다. **파일명을 직접 옮겨 적거나 다른
   이름으로 바꾸지 마세요** — pip이 만든 그대로 폴더째 옮기면 됩니다.
3. `C:\pywin32_files` 폴더를 USB 등으로 VDI의 `C:\pywin32_files`에
   그대로 복사합니다.

**② VDI에서**

4. 같은 설치 프로그램(`python-manager-26.3.msix`)으로 Python을 설치합니다.
5. 명령 프롬프트에서 (여기서는 `pip download`를 **다시 실행하지 않습니다**):
   ```
   pip install --no-index --find-links=C:\pywin32_files pywin32
   ```
6. 확인:
   ```
   python -c "import win32com.client; print('ok')"
   ```
   `ok`가 출력되면 설치가 끝난 것입니다.

## 7. 자주 나는 문제

| 증상 | 원인 / 해결 |
|---|---|
| 버튼 눌렀는데 "클라우드 경로" 안내 창이 뜸 | OneDrive 자동 저장(AutoSave)이 켜진 채로 열려 있으면 경로가 `https://...`로 인식됩니다. 이제는 버튼을 누르면 OneDrive 로컬 폴더에서 같은 파일을 자동으로 찾아서 대부분 그냥 넘어갑니다(파일이 많으면 검색에 시간이 걸릴 수 있음). 그래도 안내 창이 뜨면 **파일 → 정보**에서 자동 저장을 끄거나 동기화 폴더에서 직접 열고 재시도 — 그래도 안 되면 조직 정책으로 막혀 있는 경우라 IT 문의가 필요할 수 있습니다 |
| `dashboard_recreate.bat`/`run_live_server.bat`을 눌렀는데 검은 창이 이상한 명령어 오류를 내며 멈춤 | 예전 버전 버그였습니다 — 폴더 경로에 `&`가 들어 있으면(예: `... - SKI E&S\...`) 깨졌습니다. 최신 버전으로 다시 받으면 해결됩니다 |
| [실시간 입력 서버] 저장 시 "이미 열려 있는 통합 문서와 이름이 같습니다" | 최신 버전에서 고쳤습니다(파일을 찾는 방식을 경로 문자열 비교 → 엑셀 자체 조회로 변경). 그래도 나면 화면을 캡처해서 공유해주세요 |
| 아무도 안 쓰는데 계속 "읽기 전용"으로 열림 (다른 파일/애드인 포함) | 보통은 엑셀/대시보드 탭을 닫으면 서버가 자동 종료되며 같이 풀립니다. 그래도 안 풀리면 `stop_live_server.bat` 실행 → 그래도 안 풀리면 작업 관리자 → 자세히 탭에서 화면에 안 보이는 `EXCEL.EXE` 종료 → 그래도 안 되면 같은 폴더의 `~$파일명.xlsm` 잠금 파일 삭제(아무도 안 쓰는 게 확실할 때만) |
| 대시보드 탭을 닫았는데 서버가 계속 떠 있는 것 같음 | 브라우저를 통째로 강제 종료했거나 네트워크가 불안정하면 탭 종료 신호가 서버에 못 갈 수 있습니다 — 이때는 `stop_live_server.bat`으로 수동 종료하세요 |
| pywin32 없다는 오류 | 5절 참고 |
| `python`을 못 찾는다는 오류 | 2절의 "Python이 안 깔려 있다면" 참고 (python-embed 배치) |
| VBA 모듈 가져오기에서 한글이 깨짐 / "허가된 개체 이름이 아닙니다" 오류 | ZIP이 아니라 개별 Raw 파일로 저장했을 가능성이 큽니다 — `vba-form/README.md`의 해당 절차 참고 |
| [실시간 입력 서버 시작]을 눌렀는데 브라우저도 안 열리고 아무 반응이 없어 보임 | 콘솔 창이 없어서 진행 상황이 안 보일 뿐, 문제가 있으면 최대 30초 안에 안내 창이 뜹니다 — 잠깐 기다려보세요. 계속 아무것도 안 뜨면 `_program\static-dashboard\live_server.log` 파일을 열어 마지막 부분을 확인하거나, `_program\static-dashboard\run_live_server.bat`을 직접 더블클릭해 콘솔 창으로 진행 상황을 봐주세요 |

원인을 못 찾는 오류가 뜨면, 뜬 창을 그대로 캡처해서 공유해주세요 — 대부분
어느 단계에서 어떤 원본 오류가 났는지까지 같이 표시되도록 만들어뒀습니다.
