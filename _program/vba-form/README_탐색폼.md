# PPA 관계형 데이터 탐색 · 편집 (엑셀 VBA)

HTML 대시보드의 **[탐색] 탭을 엑셀 안으로 옮긴 것**입니다. 다른 점은 하나 —
여기서는 결과를 **보기만 하는 게 아니라 그 자리에서 고쳐서 원본 시트에 반영**할
수 있습니다.

| | HTML 탐색 탭 | 이 엑셀 폼 |
|---|---|---|
| 기준 표 / 연결 표 / 출력 컬럼 선택 | O | O |
| 누락 데이터(LEFT JOIN) | O | O |
| 검색 · 필터 · 정렬 | O | O (+ 엑셀 자동필터) |
| 내려받기 | CSV/Excel/MD | 새 통합문서로 내보내기 |
| **값 수정** | **불가 (조회 전용)** | **가능** |

## 화면

```
[설정 적용][조회 실행][변경 저장][되돌리기][엑셀로 내보내기][초기화]

관계형 데이터 탐색 · 편집
빠른 조회      [발전소 중 구매계약 없음        ▼]
1. 기준 표     [발전소 ▼]
2. 연결할 표   ☑발전소(기준)  ☑구매계약 1  ☐수요기업 5  ☐판매계약 4  ☐전기사용지 3  ☐수급매칭 2
3. 출력 컬럼   보고 싶은 컬럼만 체크하세요
   발전소      ☑발전소ID ☑발전소명 ☑발전법인명 ☐설비용량(MW) ☐발전원 ☐Readiness ☐MGA_Supply
   구매계약    ☑구매계약ID ☐발전소ID ☐구매계약용량(MW) ☐구매단가(원/kWh) …
   수요기업    (연결 안 됨 - 회색)
   …
4. 조건        [한 곳이라도 빠진 행만 (누락) ▼]      검색어 [        ]
상태           발전소 기준 208행 · 연결 표 1개 · 출력 컬럼 4개  (칸을 고친 뒤 [변경 저장])

결과   ┌발전소──────┬발전소──────┬발전소────────┬구매계약──────┐
       │발전소ID    │발전소명     │발전법인명     │구매계약ID    │
       │P0003       │발전소3호    │법인3(주)      │      -       │
       │P0009       │발전소9호    │법인9(주)      │      -       │
```

**연결할 표**의 숫자는 기준 표에서 몇 단계 떨어졌는지입니다. 중간에 거쳐야 하는
표는 체크하지 않아도 자동으로 따라옵니다(예: 발전소 → 수급매칭을 고르면 구매계약이
자동 포함).

## 칸 색으로 편집 가능 여부를 표시합니다

| 색 | 뜻 |
|---|---|
| 흰색 | **편집 가능** — 고치고 [변경 저장] |
| 연한 청록 (굵은 글씨) | **PK(ID)** — 여기서는 못 바꿉니다 |
| 주황 `-` | **연결 상대 없음** — 쓸 레코드가 없어 편집 불가 |

머리글도 색으로 구분합니다: 진한 청록 = PK, 연보라 = FK, 회색 = 일반.

## 편집 안전장치

`[변경 저장]`을 누르면 바로 쓰지 않고 **무엇이 어떻게 바뀌는지 먼저 보여줍니다.**

```
아래 3건을 원본 시트에 반영합니다.

· 구매계약 구매-0456 / 구매단가(원/kWh) : 142 → 148
· 구매계약 구매-0456 / 구매 담당자 : 박창옥 → 최기철
· 발전소 P0123 / 설비용량(MW) : 3.0 → 3.5

계속할까요?   [예] [아니오]
```

저장 전에 아래를 검사해 하나라도 걸리면 **저장을 멈춥니다.**

- **PK 변경 금지** — ID를 바꾸면 다른 표의 FK가 전부 깨지므로 막습니다
  (ID를 정말 바꿔야 하면 원본 시트에서 관련 FK까지 함께 손봐야 합니다)
- **FK 검증** — 고친 값에 해당하는 부모 레코드가 실제로 있는지 확인
- **충돌 감지** — 1:N 전개로 같은 원본 행이 여러 줄에 보일 때, 그 줄들을 서로 다른
  값으로 고쳤다면 어느 쪽을 써야 할지 알 수 없으므로 중단하고 알려줍니다
- **빈 칸 경고** — 연결 상대가 없는 `-` 칸에 값을 넣었다면 쓸 대상이 없다고 알려줍니다
  (새 레코드는 `입력폼` 에서 만드세요)

`[되돌리기]`는 화면에서 고치던 내용을 버리고 원본 값으로 다시 불러옵니다.

## 빠른 조회

스키마의 FK에서 자동으로 뽑은 "빠진 것 찾기" 질문들입니다. 고르면 기준 표 ·
연결 표 · 누락 필터가 한 번에 맞춰지고 바로 조회됩니다.

- 발전소 중 구매계약 없음
- 수요기업 중 판매계약 없음
- 판매계약 중 전기사용지 없음
- 전기사용지 중 수급매칭 없음
- 구매계약 중 수급매칭 없음

> 빠른 조회 드롭다운을 고른 뒤에는 **[설정 적용]** 이 아니라 화면 위 버튼 중
> **[조회 실행]** 을 누르거나, 아래 *자동 반영* 을 설정해두세요.

## 설치

1. 원본 xlsm의 **사본**에서 먼저 시험하세요.
2. GitHub에서 **Code → Download ZIP** 으로 받습니다
   (Raw 우클릭 저장은 UTF-8이 되어 한글이 깨집니다).
3. 엑셀 `Alt`+`F11` → **파일 → 파일 가져오기** → `PPA_탐색폼.bas`
4. `Alt`+`F8` → **탐색_만들기** 실행

`입력폼`(PPA_InputForm)과 **별개로 동작**합니다. 둘 다 가져와도 되고, 하나만
가져와도 됩니다. 여기서 수정한 내용을 팀원들에게 보여줄 HTML 대시보드로
반영하려면 `PPA_대시보드생성`(`README_대시보드생성.md`)의 버튼을 쓰세요.

### (선택) 기준 표를 고르는 즉시 반영

기본은 기준 표를 바꾼 뒤 `[설정 적용]`을 눌러야 합니다. 즉시 반영되게 하려면
VBE에서 **탐색** 시트를 더블클릭하고 아래를 붙여넣으세요.

```vba
Private Sub Worksheet_Change(ByVal Target As Range)
    탐색_변경감지 Target
End Sub
```

## 만들어지는 시트

| 시트 | 용도 |
|---|---|
| `탐색` | 작업 화면 |
| `_탐색맵` | 결과 각 줄이 원본의 몇 번째 행인지 기억 (자동 숨김, 건드리지 마세요) |

기존 `T_*` 시트의 구조는 바꾸지 않습니다. 머리글 텍스트로 열을 찾으므로 열 순서가
달라도 동작합니다.

## 성능

결과는 최대 5,000행까지 만듭니다. 연결 표를 많이 붙이면 1:N 전개로 행이 급격히
늘어나므로(한 전기사용지가 여러 구매계약에서 공급받는 구조), 상한을 넘으면 잘라내고
알려줍니다. 그럴 때는 연결 표를 줄이거나 검색어·누락 필터로 좁혀주세요.

## 확인된 범위 / 먼저 봐주실 것

정적 점검(프로시저 호출 인자 수, 블록 짝, 중복 선언, `Option Explicit` 위반)은
통과했지만 **이 환경에는 엑셀이 없어 실제로 실행해보지 못했습니다.**
반드시 **사본에서** 아래 순서로 확인해주세요.

1. `탐색_만들기` 가 오류 없이 끝나고 체크박스가 그려지는지
2. 기준 표를 `발전소`로 두고 `구매계약`을 체크 → **[설정 적용]** → 구매계약 줄에
   컬럼 체크박스가 생기는지
3. **[조회 실행]** → 결과가 나오고, 구매계약이 없는 발전소는 `-` 로 표시되는지
4. 흰색 칸 하나를 고치고 **[변경 저장]** → 미리보기에 그 항목만 뜨는지,
   `예` 후 원본 시트에 반영됐는지
5. PK 칸(청록)을 고치고 저장 → **거부 메시지**가 뜨는지
6. `빠른 조회` 에서 "발전소 중 구매계약 없음" → 누락 목록이 나오는지

이 중 걸리는 게 있으면 화면을 캡처해 보내주세요.

## 오류가 나면 (예: "런타임 오류 438")

버전에 따라 일부 서식 기능(체크박스 폰트, 버튼 그림자, 격자선 숨김 등)이
엑셀 빌드마다 다르게 동작할 수 있습니다. 이런 부가 서식은 실패해도 핵심 기능이
멈추지 않도록 안전하게 건너뛰게 했고, 대신 **"PPA 탐색 - 오류"** 라는 창이
뜨면서 어느 단계·어느 프로시저에서 무슨 오류(번호·설명)가 났는지 정확히
보여줍니다. 오류가 나면 그 창을 캡처해서 보내주세요 — 이전처럼 "런타임 오류
438"만으로는 원인을 알 수 없지만, 이 창의 내용이 있으면 정확히 어느 줄인지
찾을 수 있습니다.
