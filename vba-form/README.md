# PPA 통합 입력/조회 폼 (엑셀 VBA)

`static-dashboard`의 HTML 대시보드는 **조회 전용**이라 원본 xlsm에 값을 쓸 수
없습니다. **입력**은 엑셀 안에서 해야 하므로, 같은 관계 구조(PK/FK)를 그대로
쓰면서 **여섯 개 시트를 오갈 필요 없이 한 화면에서 등록/조회/수정**하는 폼을
VBA로 만들었습니다.

## 무엇이 달라지나

지금은 한 건을 등록하려면 이렇게 해야 합니다.

```
T_발전소 시트 → 발전소 추가, 발전소ID 확인/복사
T_구매계약 시트 → 이동, 발전소ID 붙여넣기, 구매계약ID 새로 만들기
T_수요기업 시트 → 이동, 수요기업 추가
T_판매계약 시트 → 이동, 수요기업ID 붙여넣기
T_전기사용지 시트 → 이동, 판매계약ID 붙여넣기
T_수급매칭 시트 → 이동, 전기사용지ID·구매계약ID 붙여넣기
```

폼을 쓰면 **입력폼 시트 한 곳**에서 위 6개를 채우고 [저장] 한 번이면 끝납니다.
ID를 손으로 옮겨 적을 일이 없어지고, 옮겨 적다 생기던 오타(= 검증 탭의 FK 참조
오류)가 원천적으로 사라집니다.

## 화면 구성

```
PPA 통합 입력 · 조회 폼      [조회][이전][다음][불러오기][새로 만들기][저장][삭제][목록 새로고침]
조회 (ID / 이름)  [                    ]
상태              현재 상태 메시지

■ 발전소        발전소ID ▼ / 발전소명 / 발전법인명 / 설비용량(MW) / 발전원 / Readiness / MGA_Supply
■ 구매계약      구매계약ID ▼ / 발전소ID ▼ / 구매계약용량 / 구매단가 / 공급기한 / 계약기간 / 미확보 / 담당자
■ 수요기업      수요기업ID ▼ / 기업명
■ 판매계약      판매계약ID ▼ / 수요기업ID ▼ / … (12개 항목)
■ 전기사용지    전기사용지ID ▼ / 판매계약ID ▼ / 전기사용지명 / 계약용량
■ 수급매칭      수급매칭ID ▼ / 전기사용지ID ▼ / 구매계약ID ▼ / 현황
```

각 표의 **PK 칸 색으로 상태를 알려줍니다.**

| 색 | 뜻 |
|---|---|
| 흰색 | 비어 있음 — 저장할 때 ID가 자동 생성됩니다 |
| 파란색 | 기존 항목 — 값을 고치면 **원본이 수정**됩니다 |
| 초록색 | 신규 — 저장하면 새로 추가됩니다 |

## 핵심 동작

**1. 연동 드롭다운**
발전소를 고르면 구매계약 목록이 *그 발전소의 계약만* 남습니다. 수요기업 →
판매계약 → 전기사용지도 같은 방식입니다. 새 ID를 직접 타이핑하는 것도 허용합니다.

**2. 자동 채우기**
ID를 고르고 [불러오기]를 누르면 그 레코드와 위아래로 이어진 표가 전부 채워집니다.
수급매칭 하나만 골라도 전기사용지 → 판매계약 → 수요기업, 구매계약 → 발전소까지
한 번에 올라옵니다.

**3. 조회**
검색창에 ID든 발전소명이든 기업명이든 담당자든 넣고 [조회]를 누르면, 그 값이
걸리는 수급매칭 건을 모두 찾아 [이전]/[다음]으로 넘겨봅니다.

**4. 저장 전 확인**
저장을 누르면 바로 쓰지 않고 **무엇이 어떻게 바뀌는지 먼저 보여줍니다.**

```
아래 내용으로 반영됩니다.

[변경없음] 발전소  P0123
[수정] 구매계약  구매-0456
      · 구매단가(원/kWh): 142 → 148
      · 구매 담당자: 박창옥 → 최기철
[신규] 수급매칭  매칭-0468

이대로 저장할까요?   [예] [아니오]
```

**5. 검증**
저장 전에 기존 매크로와 동일한 규칙을 확인합니다 — PK 공란, FK 공란/참조 실패,
수급매칭의 (전기사용지 + 구매계약) 조합중복. 하나라도 걸리면 저장하지 않습니다.

**6. ID 자동 생성**
비워두면 **기존 ID가 쓰고 있는 규칙을 읽어서** 다음 번호를 만듭니다.
`구매-0001`…`구매-0615`가 있으면 `구매-0616`, `P001`…`P589`면 `P590`.

**7. 안전장치**
- 폼에서 **비워 둔 칸은 기존 값을 지우지 않습니다** (실수로 값이 날아가는 것 방지)
- [삭제]는 **수급매칭 행만** 지웁니다. 발전소·계약 등 상위 항목은 건드리지 않습니다
- ID는 항상 텍스트로 씁니다 (`001`이 숫자 `1`로 바뀌는 사고 방지)

## 설치

1. 원본 xlsm의 **사본**을 만들어 거기서 먼저 시험해보세요.
2. 엑셀에서 `Alt` + `F11` (VBE 열기)
3. 메뉴 → **파일** → **파일 가져오기** → `PPA_통합입력폼.bas` 선택
4. VBE를 닫고 `Alt` + `F8` → **폼_만들기** → 실행
5. `입력폼` 시트가 생기고 버튼이 놓입니다. 이후로는 버튼만 쓰면 됩니다.

### (선택) 드롭다운 고르는 즉시 자동 채우기

기본은 [불러오기] 버튼을 눌러야 채워집니다. 고르자마자 채워지게 하려면:

1. VBE에서 왼쪽 목록의 **입력폼** 시트를 더블클릭
2. 열린 코드창에 아래를 붙여넣고 저장

```vba
Private Sub Worksheet_Change(ByVal Target As Range)
    폼_변경감지 Target
End Sub
```

## 만들어지는 시트

| 시트 | 용도 |
|---|---|
| `입력폼` | 실제 작업 화면 |
| `_폼목록` | 드롭다운 원본과 조회 결과 (자동 숨김, 건드릴 필요 없음) |

기존 `T_*` 시트의 구조는 **전혀 바꾸지 않습니다.** 열을 추가하거나 순서를 바꾸지
않고, 머리글 텍스트로 열을 찾기 때문에 열 순서가 달라도 동작합니다.

## HTML 대시보드와의 역할 분담

| | 정적 HTML 대시보드 | 이 VBA 폼 |
|---|---|---|
| 위치 | 어디서나 (브라우저) | 원본 xlsm 안 |
| 조회 | 강함 (탐색·관계조회·변경·검증·내려받기) | 한 건 단위 조회 |
| 입력 | 불가 | **가능 (주 용도)** |
| 공유 | 파일 하나 전달하면 끝 | 원본을 열 수 있는 사람만 |

**입력은 VBA 폼에서, 팀 공유·보고·분석은 HTML 대시보드로** 쓰는 조합을 권장합니다.
데이터를 넣은 뒤 `.bat`을 다시 실행하면 대시보드가 갱신되고, 그때 [변경] 탭에
이번에 넣은 내용이 그대로 잡힙니다.

## 확인된 범위 / 먼저 봐주실 것

작성 후 정적 점검(프로시저 정의·호출 인자 수·블록 짝·중복 선언·`Option Explicit`
위반)은 통과했지만, **실제 엑셀에서 돌려본 것은 아닙니다.** 이 환경에는 엑셀이
없습니다. 그래서 반드시 **사본에서 먼저** 아래 순서로 확인해주세요.

1. `폼_만들기` 가 오류 없이 끝나는지 (표 구성이 다르면 어떤 열이 문제인지 알려줍니다)
2. 기존 건 하나를 [조회] → 값이 6개 구역에 제대로 뜨는지
3. 아무것도 고치지 않고 [저장] → `[변경없음]` 만 뜨는지
4. 값 하나만 바꿔 [저장] → 미리보기에 그 항목만 `→` 로 뜨는지, 원본 시트에 반영됐는지
5. 완전히 새 건을 넣어 [저장] → 6개 시트에 각각 한 행씩 생기고 ID가 서로 맞물리는지

이 5단계에서 걸리는 게 있으면 화면을 캡처해 보내주세요. 바로 잡아드리겠습니다.
